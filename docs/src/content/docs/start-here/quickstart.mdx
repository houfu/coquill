This guide walks you through preparing the **Bonterms Mutual NDA** example using Claude Cowork. You will go from zero to a completed Word document in under five minutes.

<Aside>
CoQuill includes the [Bonterms Mutual NDA](https://bonterms.com/download-center/mutual-nda) in its example templates pack. It is a real, production-quality mutual NDA released under CC BY 4.0.
</Aside>

## Get a Claude account and download the Desktop app

<Aside>
Skip this step if you already have a Claude Pro or Max account and downloaded the Desktop App.
</Aside>

<Steps>
1. Go to [Claude](https://claude.ai) and get an account. You will need at least Claude Pro (USD20/month) in order to use Cowork.

2. Download the [Claude Desktop App](https://claude.com/download) for Windows or Mac. Follow the instructions to install the app on your computer and connect it to your account.

</Steps>

## Install CoQuill

CoQuill installs once at the account level via the plugin marketplace. After install, it is available in every Cowork project you open.

<Steps>

1. **Open Claude Cowork**

   Open the Claude Desktop App and switch to the Cowork tab (Cmd+2 on Mac).

2. **Add the CoQuill marketplace**

   In the chat input, run:

   ```
   /plugin marketplace add houfu/coquill
   ```

3. **Install the plugin**

   ```
   /plugin install coquill@coquill
   ```

</Steps>

<Aside type="note" title="Sandboxed or offline?">
The example templates are distributed separately from the plugin. The next section relies on Claude downloading the pack on demand. If Claude can't run `curl` and `unzip` in your environment, grab it manually instead: [coquill-examples-latest.zip](https://github.com/houfu/coquill/releases/latest/download/coquill-examples-latest.zip). Unzip into your project's `templates/` folder so `templates/Bonterms_Mutual_NDA/Bonterms-Mutual-NDA.docx` is in place before you continue.
</Aside>

## Prepare the NDA

<Steps>

1. **Ask Claude to prepare the NDA**

   In any Cowork project, type a natural request:

   ```
   Prepare a mutual NDA with CoQuill.
   ```

   ![Screenshot showing the Cowork screen with a prompt "Prepare a mutual NDA with CoQuill" entered.](/coquill/images/quickstarts/CoQuill-start.png)

2. **Claude offers to download the examples pack**

   Since the project doesn't have any templates yet, Claude pauses and asks:

   ```
   I don't see any templates in this project yet. CoQuill publishes an
   examples pack (Bonterms Mutual NDA, invoice, meeting notes) you can
   use to try it out — would you like me to download it now?
   > Yes
   ```

   Claude fetches `coquill-examples-latest.zip` and unzips it into `templates/`. After this step you have `templates/Bonterms_Mutual_NDA/`, `templates/invoice/`, and `templates/meeting_notes/` ready to use. Subsequent documents in the same project skip this step.

3. **Claude prepares the NDA**

   Once the pack is in place, Claude matches your request to the `Bonterms_Mutual_NDA` template, analyses it for variables, and starts the interview. In the background, Claude installs the dependencies it needs and reads the template. It looks for variables and creates a plan on how to ask and group questions to fill the template.

</Steps>

<Aside>
The first time you run CoQuill on a template, Claude is running code to analyse the template, detect variables, and generate questions. This file is saved alongside the template, speeding up future runs (until the next time the template changes).
</Aside>

<Steps>
4. **Answer the interview questions**

   Claude walks through the 13 variables in the template, grouping related fields together. Here is what a typical interview looks like:

   ```
   Let's prepare the Bonterms Mutual NDA. I'll walk through the details
   with you.

   First, what is the purpose of this NDA?
   > Evaluating a potential partnership between our two companies

   What is the effective date?
   > 2026-03-01

   What is the term of the NDA?
   > 2 years

   What is the confidentiality period?
   > 3 years

   What is the governing law?
   > State of California

   Which courts will have jurisdiction?
   > State and federal courts in San Francisco, California

   Are there any additional terms?
   > None

   Now for Party 1. What is Party 1's name?
   > Acme Corp

   Party 1 signatory name and title?
   > Jane Smith, CEO

   Party 1 signing date?
   > 2026-03-01

   And Party 2. What is Party 2's name?
   > Widgets Inc

   Party 2 signatory name and title?
   > Bob Johnson, General Counsel

   Party 2 signing date?
   > 2026-03-01
   ```

5. **Confirm the values**

   Claude presents a summary of all collected values and asks you to confirm before rendering:

   ```
   Here's a summary of the NDA details:

   Purpose: Evaluating a potential partnership between our two companies
   Effective Date: 2026-03-01
   Term: 2 years
   Confidentiality Period: 3 years
   Governing Law: State of California
   Courts: State and federal courts in San Francisco, California
   Additional Terms: None
   Party 1: Acme Corp (Jane Smith, CEO) — signing 2026-03-01
   Party 2: Widgets Inc (Bob Johnson, General Counsel) — signing 2026-03-01

   Does everything look correct?
   > Yes, go ahead
   ```

6. **Get the output file**

   Claude renders the template and saves the completed document to the `output/` folder:

   ```
   Done! Your NDA has been saved to:
   output/Bonterms_Mutual_NDA_Acme_Corp_2026-03-01/Bonterms-Mutual-NDA.docx

   A transcript of this session has been saved to transcript.md in the job folder.
   ```

   Open the `.docx` file in Word, Google Docs, or any compatible application to review the final document. The `transcript.md` records the full interview — questions, answers, and confirmed values — so you can review what was discussed without scrolling through the chat.

   ![Screenshot showing the Cowork screen with a pane on the right showing the rendered contract.](/coquill/images/quickstarts/Quickstart-results.png)
</Steps>

## What just happened

Behind the scenes, CoQuill ran four steps:

1. **Discovery** -- Claude matched "mutual NDA" to the `Bonterms_Mutual_NDA` template directory in your project's `templates/` folder
2. **Analysis** -- The Analyzer skill parsed the `.docx` template, extracted all 13 variables, and produced a `manifest.yaml`
3. **Rendering** -- After you confirmed the values, the Renderer skill used `docxtpl` to fill in the template and saved the output
4. **Transcript** -- The Transcriber skill wrote a human-readable `transcript.md` recording the interview alongside your document

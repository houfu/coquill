## Prerequisites

You need the [Claude Code](https://docs.anthropic.com/en/docs/claude-code) CLI installed and authenticated.

## Installation

<Steps>

1. **Add the marketplace and install the plugin**

   Run the following commands in Claude Code:

   ```
   /plugin marketplace add houfu/coquill
   /plugin install coquill@coquill
   ```

2. **Verify the install**

   Run `/plugin` in Claude Code and confirm that `coquill` appears in the list of installed plugins.

3. **Get a starter template**

   The plugin ships the engine only — templates are distributed as a separate **examples pack**. Download it from the latest release and unzip it into your project's `templates/` folder:

   [coquill-examples-latest.zip](https://github.com/houfu/coquill/releases/latest/download/coquill-examples-latest.zip)

   After unzipping, you should see `templates/Bonterms_Mutual_NDA/`, `templates/invoice/`, and `templates/meeting_notes/`.

4. **Run your first document**

   Tell Claude: *"Prepare a mutual NDA with CoQuill"*

   Claude should find the `Bonterms_Mutual_NDA` template and start the interview.

</Steps>

<Aside type="tip">
On the first run, Claude installs the required Python packages (`docxtpl`, `pyyaml`, `jinja2`, `weasyprint`) automatically. This takes about 30 seconds and only happens once.
</Aside>

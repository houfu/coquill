## Prerequisites

You need a [Claude Cowork](https://claude.ai) account on Pro or Max. No other software is required -- Python dependencies are installed automatically the first time you run a skill.

## Install via the plugin marketplace

<Steps>

1. **Add the CoQuill marketplace**

   In Claude Cowork, open the chat input and run:

   ```
   /plugin marketplace add houfu/coquill
   ```

2. **Install the plugin**

   ```
   /plugin install coquill@coquill
   ```

   CoQuill is now available in every Cowork project on your account -- you do not need to reinstall it per-project.

3. **Get a starter template**

   The plugin ships the engine only — templates are distributed as a separate **examples pack**. Download it from the latest release and unzip it into your Cowork project's `templates/` folder:

   [coquill-examples-latest.zip](https://github.com/houfu/coquill/releases/latest/download/coquill-examples-latest.zip)

   After unzipping, you should see `templates/Bonterms_Mutual_NDA/`, `templates/invoice/`, and `templates/meeting_notes/`.

4. **Verify the install**

   In the same Cowork project, tell Claude: *"Prepare a mutual NDA with CoQuill"*

   Claude should find the `Bonterms_Mutual_NDA` template and start the interview.

</Steps>

<Aside type="tip">
On the first run, Claude installs the required Python packages (`docxtpl`, `pyyaml`, `jinja2`, `weasyprint`) automatically. The first install takes about 30 seconds; after that, packages are cached locally.
</Aside>

## Adding your own templates

Once CoQuill is installed, drop your templates into any Cowork project's files:

```
templates/
  my_contract/
    my_contract.docx
```

Claude finds templates inside the active project automatically. See [Use Your Own Templates](/coquill/feature-tour/your-own-templates/) for the full template authoring flow.

## Sharing a template stack with a colleague

CoQuill is installed once, per account. Template stacks are shared separately -- zip up a `templates/` folder, send it to a colleague who has CoQuill installed, and they drop it into a Cowork project of their own.
